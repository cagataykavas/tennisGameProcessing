# Security and privacy

## Supported version

Security fixes target the latest version on the default branch.

## Reporting

Please report a suspected vulnerability privately through GitHub's security advisory
workflow rather than opening a public issue. Include reproduction steps, affected
version, and impact when possible.

## Data handling

The application processes video locally and makes no network requests. Generated
artifacts may contain identifiable people from the input video; review them before
sharing. Input videos and generated media are ignored by Git by default.

Do not use this baseline for covert surveillance, identity recognition, or automated
decisions about people. It assigns temporary court-relative track IDs, not identities.
